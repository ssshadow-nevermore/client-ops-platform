# PRODUCT_HYPOTHESIS.md

## Проблема

Разработчики и небольшие агентства, которые сопровождают несколько клиентских сайтов, вынуждены постоянно переключаться между разными сервисами: GitHub, Vercel, Supabase, Sentry, аналитикой, CMS, хостингом и другими инструментами.

При этом часть рутинных задач остаётся ручной:

* проверка состояния проектов;
* поиск проблем;
* мелкие правки контента;
* контроль клиентских изменений;
* проверка деплоев;
* работа с доступами;
* понимание, какой проект требует внимания.

По мере роста количества клиентских сайтов сопровождение становится всё менее масштабируемым.

## Гипотеза

Единая система администрирования и контроля клиентских веб-проектов позволит разработчику:

* быстрее понимать состояние всех проектов;
* раньше замечать проблемы;
* безопасно передавать клиенту управление контентом;
* уменьшать количество ручных проверок;
* сокращать число мелких обращений от клиентов;
* сопровождать больше проектов без пропорционального роста нагрузки.

## Что представляет собой продукт

Продукт — это не конструктор сайтов и не новая универсальная CMS.

Это система для сопровождения уже существующих веб-проектов, которая объединяет:

* multi-project dashboard;
* project health;
* client-safe CMS;
* developer control panel;
* roles и permissions;
* integrations;
* audit log.

## Основная ценность

Главная ценность продукта:

> Меньше ручной рутины, быстрее обнаружение проблем, безопасное делегирование клиенту и более удобное сопровождение нескольких проектов из одного места.

## Главная продуктовая гипотеза

Если разработчик может из одной системы быстро понять состояние всех клиентских проектов и выполнять основные действия сопровождения, то обслуживание сайтов станет быстрее, безопаснее и лучше масштабироваться.
