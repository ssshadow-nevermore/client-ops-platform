# TARGET_USER.md

## Основной пользователь

Основной пользователь первой версии — solo-разработчик, фрилансер или небольшая веб-студия, которые сопровождают несколько клиентских сайтов после запуска.

## Типичный профиль

Пользователь:

* ведёт несколько активных клиентских проектов;
* самостоятельно отвечает за поддержку сайтов;
* использует несколько внешних сервисов;
* периодически получает от клиентов запросы на мелкие изменения;
* хочет быстрее понимать состояние всех проектов;
* не хочет вручную проверять каждый сайт по отдельности;
* не хочет давать клиенту полный технический доступ к проекту.

## Основные боли

Пользователь сталкивается с:

* большим количеством разрозненных сервисов;
* отсутствием единой картины по всем сайтам;
* необходимостью вручную проверять состояние проектов;
* ситуациями, когда о проблеме первым сообщает клиент;
* постоянными мелкими правками контента;
* сложностью безопасно выдавать клиентам доступ;
* ростом нагрузки при увеличении числа проектов.

## Вторичный пользователь

Клиент владельца сайта.

Клиенту нужна простая система, где он может безопасно:

* менять тексты;
* менять цены;
* менять изображения;
* управлять доступным бизнес-контентом;
* не иметь доступа к техническим настройкам.

## Для кого продукт не предназначен на первом этапе

Первая версия не ориентирована на:

* крупных enterprise-команд;
* владельцев одного простого сайта;
* пользователей, которым нужен визуальный конструктор;
* команды, которым нужна полноценная DevOps-платформа;
* пользователей, которым нужна новая универсальная CMS.
